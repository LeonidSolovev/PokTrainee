# Покерный тренажёр

Один файл `index.html`, без сборки и зависимостей. Открывается в браузере (телефон или компьютер), прогресс хранится в localStorage.

## Режимы
- **Раздача**: полная раздача на 5 игроков со стеками (префлоп → флоп → тёрн → ривер → вскрытие, олл-ин, побочные банки). Фильтр по теме: префлоп, размер рейза, сила руки, шансы банка, ауты, ривер. Твой стек переходит из раздачи в раздачу (старт 100 ББ, при стеке меньше 3 ББ автоматическая докупка), стеки соперников случайные. Галочка «Замечай дро» задаёт в случайный момент вопрос на время: есть ли у тебя флеш-дро, стрит-дро, гатшот или два дро сразу (тема «Замечать дро» есть и в списке тем). За столом всегда одни и те же четыре друга со своими стилями игры, а твоя позиция меняется по кругу (баттон идёт по часовой стрелке). Галочки: рейзы соперников до флопа, честная раздача, блиц на время.
- **Счёт шансов**: раздачи сразу с дро, вопросы на ауты, шанс собрать и цену колла.
- **Вскрытие**: борд и две руки, ответ «А / Б / сплит». Случаи: кикер, фулл-хаус, колесо A-2-3-4-5, игра борда, равные флеши.
- **Мини-тренажёры**: комбинация на время, какая рука старше, нужный шанс.
- **Мои ошибки**: повтор решений, где была оценка «ошибка».

## Журнал
Каждое решение и ответ пишутся в журнал (до 500 записей). Блок «Журнал и выгрузка для тренера» формирует сводку и записи в JSON, по одной на строку, с кнопкой «Копировать».

## Как добавлять новую тему
1. Текст урока: массив `LESSONS` в начале скрипта.
2. Правила оценки: `judge` (после флопа), `judgePre` / `judgeVsRaise` (префлоп), стартовые руки в `tier`.
3. Новая тема статистики и журнала: запись в `TOPICS`.
4. Новый вопрос: `makeQ` (в раздачах), `startMini` (мини), `SHOWCASES` (вскрытие).
5. Поведение соперников: `STY` и `aiAct`.
6. Грубая оценка «цены ошибки»: `evPre`, `evPost`.
