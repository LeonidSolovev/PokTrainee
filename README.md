# Покерный тренажёр

Один файл `index.html`, без сборки и зависимостей. Открывается в браузере (телефон или компьютер), прогресс хранится в localStorage.

## Режимы
- **Раздача**: полная раздача на 5 игроков (префлоп → флоп → тёрн → ривер → вскрытие). Фильтр по теме: только префлоп, сила руки, шансы банка, ауты, ривер.
- **Счёт шансов**: раздачи сразу с дро, вопросы на ауты, шанс собрать и цену колла.
- **Мини-тренажёры**: какая комбинация старше, кто выиграет на вскрытии, нужный шанс.
- **Мои ошибки**: повтор решений, где была оценка «ошибка». Верный ответ убирает ошибку из списка.

## Как добавлять новую тему
1. Текст урока: массив `LESSONS` в начале скрипта.
2. Правила оценки: `judge` (после флопа) или `judgePre` / `judgeVsRaise` (префлоп).
3. Новая тема в статистике: запись в `TOPICS`.
4. Новый вопрос-квиз: `makeQ` (в раздачах) или `startMini` (отдельные).
5. Поведение соперников: `STY` (стили) и `aiAct`.

Доп. сценарий «Рейзы соперников до флопа» не из пройденных уроков, включается галочкой.
